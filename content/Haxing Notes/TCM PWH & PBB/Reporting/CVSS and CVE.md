### CVSS
Common Vulnerability Scoring System
>Used for scoring vulnerabilities according to multiple factors

| Rating   | CVSS Score |
| -------- | ---------- |
| None     | 0.0        |
| Low      | 0.1-3.9    |
| Medium   | 4.0-6.9    |
| High     | 7.0-8.9    |
| Critical | 9.0-10     |
#### CVSS Calculators
[NVD NIST](https://nvd.nist.gov/vuln-metrics/cvss/v3-calculator)
CVSS3 Advisor - Gives ways to upgrade a vulnerability for a higher payout
#### CVSS Vector String
> Describes the specific aspects of a vulnerability
> Contains: 
> 1. CVSS version (green)
> 2. Base metrics (orange)
> 3. Temporal Metrics (blue)
> 4. Environmental metrics (red)
